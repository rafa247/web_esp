1. Instalación Rápida y Registro Automático en el PATH

El binario oficial esp.exe (v2.1.0) incluye el intérprete, compilador nativo, generador de ISOs booteables y todos los módulos listos para usarse sin dependencias externas:

  1. Descarga el ejecutable haciendo clic en el botón superior Descargar ESP v2.1.0 (Windows 64-bit).
  2. Mueve esp.exe a una carpeta permanente (por ejemplo, C:\ESP\esp.exe o C:\Program Files\ESP\esp.exe).
  3. La primera vez que ejecutas esp.exe, el propio binario verifica su ubicación física y se auto-registra en el PATH de tu usuario para que puedas ejecutar esp archivo.esp desde cualquier carpeta.

Abre una terminal nueva (PowerShell o CMD) y comprueba la instalación (y su hash SHA-256 si deseas verificar integridad):

esp version
esp ruta
Get-FileHash "$HOME\Downloads\esp.exe" -Algorithm SHA256

🛡 ¿Qué hacer si Windows Defender o SmartScreen bloquea el ejecutable?

Como ESP 2.1.0 es un proyecto independiente recién compilado y no cuenta con un certificado comercial de pago de Microsoft, Windows Defender SmartScreen puede mostrar una pantalla azul con el mensaje "Windows protegió su PC" o bloquear la descarga en el navegador.

Opción A: Permitir desde la ventana de Windows SmartScreen (Recomendado)

  1. Cuando aparezca la ventana azul "Windows protegió su PC", haz clic en el enlace subrayado Más información (situado debajo del texto de advertencia).
  2. Aparecerá el botón Ejecutar de todas formas en la parte inferior derecha. Haz clic en él para iniciar esp.exe normalmente.

Opción B: Desbloquear el archivo desde Propiedades o PowerShell

  1. Haz clic derecho sobre esp.exe y selecciona Propiedades.
  2. En la pestaña General (abajo a la derecha), marca la casilla Desbloquear y pulsa Aceptar.
  3. O bien ejecuta este comando en PowerShell para quitar la marca de descarga de Internet:
Unblock-File -Path "$HOME\Downloads\esp.exe"

Opción C: Si Antivirus de Windows Defender lo pone en cuarentena

  1. Abre Seguridad de Windows → Protección contra virus y amenazas → Historial de protección.
  2. Selecciona el evento reciente de esp.exe, pulsa en Acciones → Restaurar.
  3. Para evitar futuras alertas al compilar tus propios .exe con esp compilar, añade tu carpeta de instalación (C:\ESP) en Administrar la configuración → Exclusiones.

2. Primeros Pasos y Comandos Principales

Ejecutar un archivo .esp

Crea un archivo hola.esp y ejecútalo directamente desde cualquier carpeta:

mostrar("¡Hola desde ESP 2.1.0!")
esp hola.esp

Compilar a Ejecutable Nativo (.exe)

Convierte tu código ESP en un binario nativo independiente optimizado con -O3:

esp compilar hola.esp -o hola.exe -O3
.\hola.exe

Subcomandos CLI Disponibles

  • esp — Inicia la consola interactiva (REPL).
  • esp <archivo.esp> — Ejecuta un script ESP.
  • esp verificar <archivo.esp> — Valida la sintaxis sin ejecutar.
  • esp compilar <archivo.esp> [-o salida] [--formato exe|dll|so|dylib|estatica|ll|cpp] [-O0|-O1|-O2|-O3] — Compila a binario nativo, biblioteca o código intermedio.
  • esp formatear <archivo.esp> — Indenta automáticamente los bloques fin.
  • esp instalar <paquete> [--url <url>] [--sha256 <hash>] — Descarga e instala paquetes verificando SHA-256.
  • esp lsp — Inicia el servidor Language Server Protocol (JSON-RPC) para editores.
  • esp nodo <escuchar|conectar|ejecutar> — Ejecución distribuida en cluster por red IP.

3. Documentación Completa de Palabras Clave y Ejemplos

3.1. variable / var

Declara una variable mutable en el ámbito actual.

variable puntos = 10
puntos = puntos + 5
mostrar(puntos)

3.2. constante / const

Declara una constante que no puede reasignarse.

constante VERSION_APP = "2.1.0"
mostrar(VERSION_APP)

3.3. verdadero / true

Valor booleano verdadero.

variable listo = verdadero
si listo
    mostrar("Listo")
fin

3.4. falso / false

Valor booleano falso.

variable error_critico = falso
si no error_critico
    mostrar("Sin errores")
fin

3.5. nulo / null

Representa ausencia de valor.

variable dato = nulo
si dato == nulo
    mostrar("Es nulo")
fin

3.6. funcion / function / fn

Define una función con parámetros y cuerpo.

funcion saludar(nombre)
    devolver "Hola, " + nombre
fin
mostrar(saludar("ESP"))

3.7. devolver / return

Retorna un valor desde una función.

funcion doble(n)
    devolver n * 2
fin
mostrar(doble(8))

3.8. fin / end

Cierra bloques de funciones, clases, condicionales, bucles, páginas y estilos.

si verdadero
    mostrar("Dentro del bloque")
fin

3.9. si / if

Evalúa una condición y ejecuta su bloque si es verdadera.

variable edad = 20
si edad >= 18
    mostrar("Mayor de edad")
fin

3.10. si_no_si / elseif

Agrega condiciones alternativas intermedias en un bloque si.

variable nota = 85
si nota >= 90
    mostrar("A")
si_no_si nota >= 80
    mostrar("B")
fin

3.11. sino / si_no / else

Ejecuta un bloque cuando ninguna condición anterior se cumple.

variable x = 1
si x > 10
    mostrar("Grande")
sino
    mostrar("Pequeno")
fin

3.12. mientras / while

Repite un bloque mientras la condición sea verdadera.

variable c = 1
mientras c <= 3
    mostrar(c)
    c = c + 1
fin

3.13. para ... hasta ... paso

Bucle numérico desde inicio hasta fin con incremento opcional.

para i = 1 hasta 5 paso 2
    mostrar(i)
fin

3.14. para ... en

Recorre los elementos de una lista o los caracteres de un texto.

variable items = ["a", "b", "c"]
para item en items
    mostrar(item)
fin

3.15. romper / break

Sale inmediatamente de un bucle mientras o para.

para i = 1 hasta 10
    si i == 4
        romper
    fin
    mostrar(i)
fin

3.16. continuar / continue

Salta a la siguiente iteración del bucle.

para i = 1 hasta 5
    si i == 2
        continuar
    fin
    mostrar(i)
fin

3.17. y / and

Operador lógico Y (conjunción en cortocircuito).

si verdadero y verdadero
    mostrar("Ambos verdaderos")
fin

3.18. o / or

Operador lógico O (disyunción en cortocircuito).

si falso o verdadero
    mostrar("Al menos uno verdadero")
fin

3.19. no / not

Operador lógico de negación.

si no falso
    mostrar("Negacion verdadera")
fin

3.20. clase / class

Define una clase con propiedades y métodos.

clase Contador
    publico variable valor = 0
    publico funcion incrementar()
        este.valor = este.valor + 1
    fin
fin
variable cnt = Contador()
cnt.incrementar()
mostrar(cnt.valor)

3.21. hereda / extends

Permite que una clase herede propiedades y métodos de otra.

clase Base
    publico variable origen = "base"
fin
clase Hija hereda Base
    publico funcion mostrar_origen()
        mostrar(este.origen)
    fin
fin
variable h = Hija()
h.mostrar_origen()

3.22. este / this

Referencia a la instancia actual dentro de un método.

clase Usuario
    publico variable nick = ""
    publico funcion iniciar(n)
        este.nick = n
    fin
fin

3.23. super

Referencia a la clase padre en métodos de una clase hija.

clase Padre
    publico funcion info()
        mostrar("Info padre")
    fin
fin
clase Hijo hereda Padre
    publico funcion info_hijo()
        mostrar(super)
    fin
fin

3.24. publico / publica / public

Marca un miembro o declaración como público.

clase Caja
    publico variable contenido = "ok"
fin

3.25. privado / privada / private

Restringe el acceso a propiedades o métodos privados.

clase Secreto
    privado variable clave = "1234"
    publico funcion ver()
        devolver este.clave
    fin
fin

3.26. conseguir / importar

Carga un módulo estándar, local o remoto.

conseguir matematicas
mostrar(matematicas.PI)

3.27. como / as

Asigna un alias al importar un módulo.

conseguir matematicas como mat
mostrar(mat.abs(-9))

3.28. exportar / export

Marca un símbolo del ámbito actual como exportado.

variable API_PUBLICA = 1
exportar API_PUBLICA

3.29. intenta / try

Inicia un bloque protegido para capturar errores en ejecución.

intenta
    variable r = 10 / 2
    mostrar(r)
si_no_puede e
    mostrar(e)
fin

3.30. si_no_puede / catch

Captura y maneja el error ocurrido en intenta.

intenta
    variable mala = 1 / 0
si_no_puede err
    mostrar("Capturado: " + err)
fin

3.31. base_datos

Abre o selecciona una base de datos SQL.

base_datos "sistema.db"
crear_tabla logs(id, mensaje)

3.32. crear_tabla

Crea una tabla en la base de datos activa.

crear_tabla notas(id, titulo)
insertar_en notas(id, titulo) valores (1, "Inicio")

3.33. insertar_en / valores

Inserta registros en una tabla.

insertar_en notas(id, titulo) valores (2, "Segundo")

3.34. seleccionar / de / donde / ordenar_por / limite

Consulta registros con filtros, orden y límite.

variable filas = seleccionar * de notas donde id >= 1 ordenar_por id desc limite 10
mostrar(filas)

3.35. actualizar / poner

Actualiza columnas de filas que cumplan una condición.

actualizar notas poner titulo = "Editado" donde id = 1

3.36. eliminar_de

Elimina filas de una tabla.

eliminar_de notas donde id = 2

3.37. pagina

Define una página web completa con estilos, elementos y scripts.

pagina "Portal ESP"
    encabezado "Hola Web"
    parrafo "Generado desde ESP"
fin

3.38. estilo

Define reglas de estilo CSS para un selector.

pagina "Estilos"
    estilo body
        fondo = "#080c17"
        color_texto = "#f1f5f9"
    fin
fin

3.39. script

Inserta lógica transpilada a JavaScript en la página.

pagina "Script"
    script
        consola("Listo")
    fin
fin

3.40. encabezado / subtitulo / parrafo

Elementos de texto estructurado en una página ESP.

pagina "Textos"
    encabezado "Titulo"
    subtitulo "Subtitulo"
    parrafo "Contenido del parrafo"
fin

3.41. boton / al_clic

Crea un botón interactivo con manejador al_clic.

pagina "Boton"
    boton "Click" al_clic
        alerta("Pulsado")
    fin
fin

3.42. entrada / enlace / imagen / contenedor

Controles de formulario, enlaces, imágenes y contenedores.

pagina "Componentes"
    contenedor "caja"
        entrada "Nombre"
        enlace "Web", "https://rafa247.github.io/web_esp/"
        imagen "logo.png", "Logo ESP"
    fin
fin
