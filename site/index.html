1. Instalación y Registro Automático en el PATH

El binario esp.exe (v2.0.0) incluye intérprete interactivo (REPL), compilador nativo y módulos estándar en un solo ejecutable:

  1. Descarga esp.exe desde el botón superior.
  2. Guárdalo en una carpeta permanente, por ejemplo C:\ESP\esp.exe.
  3. Al ejecutarlo por primera vez, verifica su ruta y se registra en el PATH de usuario para invocarse como esp desde cualquier carpeta.
esp version
esp ruta
Get-FileHash "$HOME\Downloads\esp.exe" -Algorithm SHA256

🛡 ¿Qué hacer si Windows Defender o SmartScreen bloquea el ejecutable?

Como ESP 2.0.0 es un proyecto independiente sin certificado comercial de pago de Microsoft, SmartScreen o Windows Defender pueden mostrar una advertencia inicial.

Opción A: Permitir en Windows SmartScreen

  1. En la ventana "Windows protegió su PC", haz clic en Más información.
  2. Pulsa Ejecutar de todas formas para abrir esp.exe.

Opción B: Desbloquear desde PowerShell o Propiedades

Unblock-File -Path "$HOME\Downloads\esp.exe"

Opción C: Restaurar o excluir en Seguridad de Windows

  1. Abre Seguridad de Windows → Protección contra virus y amenazas → Historial de protección y restaura esp.exe si fue puesto en cuarentena.
  2. Agrega tu carpeta de trabajo o compilación (por ejemplo C:\ESP) en Exclusiones.

3. Documentación y Ejemplos de Cada Palabra Clave

A. Variables, Constantes y Literales

variable Alias: var

Declara una variable mutable cuyo valor puede asignarse o modificarse durante la ejecución.

variable contador = 0
contador = contador + 5
mostrar(contador)
constante Alias: const

Declara un valor constante que debe inicializarse al definirse y no puede reasignarse.

constante VERSION_APP = "2.0.0"
mostrar(VERSION_APP)
verdadero y falso Alias: true, false

Literales booleanos para representar valores lógicos de verdad o falsedad.

variable activo = verdadero
variable suspendido = falso
mostrar(activo)
mostrar(suspendido)
nulo Alias: null

Representa un valor vacío o inexistente.

variable resultado = nulo
si resultado == nulo
    mostrar("Sin valor asignado")
fin

B. Funciones, Retorno, Cierre de Bloques y POO

funcion Alias: function, fn

Define una función reutilizable o un método de clase, con soporte para parámetros por defecto.

funcion saludar(nombre = "mundo")
    mostrar("Hola, " + nombre)
fin

saludar("Rafa")
saludar()
devolver Alias: return

Sale de la función actual y devuelve un valor al llamador.

funcion doble(x)
    devolver x * 2
fin

mostrar(doble(7))
fin Alias: end

Cierra cualquier bloque delimitado (funcion, clase, si, mientras, para, intenta, pagina, estilo, script y contenedor).

si verdadero
    mostrar("Bloque cerrado con fin")
fin
clase Alias: class

Define un molde con propiedades y métodos para instanciar objetos.

clase Usuario
    publico variable nombre = ""
    publico funcion iniciar(n)
        este.nombre = n
    fin
fin

variable u = Usuario("Ana")
mostrar(u.nombre)
hereda Alias: extends, de

Permite que una clase herede propiedades y métodos de otra clase.

clase Animal
    publico funcion hablar()
        devolver "Sonido"
    fin
fin

clase Perro hereda Animal
    publico funcion ladrar()
        devolver "Guau"
    fin
fin

variable p = Perro()
mostrar(p.hablar())
mostrar(p.ladrar())
este Alias: this

Accede a las propiedades o métodos de la instancia actual dentro de un método.

clase Caja
    publico variable valor = 0
    publico funcion establecer(v)
        este.valor = v
    fin
fin

variable c = Caja()
c.establecer(42)
mostrar(c.valor)
super

Invoca o accede a miembros definidos en la clase padre desde una subclase.

clase Padre
    publico funcion iniciar()
        mostrar("Padre iniciado")
    fin
fin

clase Hijo hereda Padre
    publico funcion iniciar()
        super.iniciar()
        mostrar("Hijo iniciado")
    fin
fin

variable h = Hijo()
h.iniciar()
publico y privado Alias: publica, public / privada, private

Modificadores de visibilidad para propiedades, métodos y declaraciones.

clase Boveda
    privado variable secreto = "1234"
    publico funcion leer_clave()
        devolver este.secreto
    fin
fin

variable b = Boveda()
mostrar(b.leer_clave())

C. Condicionales, Bucles, Lógicos, Módulos y Excepciones

si, si_no_si y sino Alias: if, elseif, si_no, else

Evalúan condiciones y ejecutan la rama correspondiente según el resultado booleano.

variable nota = 85
si nota >= 90
    mostrar("Excelente")
si_no_si nota >= 70
    mostrar("Aprobado")
sino
    mostrar("Reprobado")
fin
mientras Alias: while

Repite un bloque de código mientras la condición siga siendo verdadera.

variable n = 1
mientras n <= 3
    mostrar(n)
    n = n + 1
fin
para, hasta, paso y en Alias: for, to, step, in

Crea bucles numéricos con hasta (y paso opcional) o recorre elementos con en.

para i = 0 hasta 6 paso 2
    mostrar(i)
fin

para fruta en ["manzana", "pera"]
    mostrar(fruta)
fin
romper y continuar Alias: break, continue

romper detiene el bucle actual; continuar pasa directamente a la siguiente iteración.

para i = 1 hasta 5
    si i == 2
        continuar
    fin
    si i == 4
        romper
    fin
    mostrar(i)
fin
y, o y no Alias: and, or, not

Operadores lógicos para combinar o negar expresiones booleanas.

variable x = 5
si (x > 0 y x < 10) o no falso
    mostrar("Condición lógica verdadera")
fin
conseguir, como y exportar Alias: importar, as, export

conseguir importa módulos o archivos, como define un alias y exportar expone un símbolo.

conseguir matematicas como mat
mostrar(mat.raiz(16))

funcion helper()
    devolver "ok"
fin
exportar helper
intenta y si_no_puede Alias: try, catch

Captura errores en tiempo de ejecución sin detener abruptamente el programa.

intenta
    mostrar(10 / 0)
si_no_puede error
    mostrar("Capturado: " + error)
fin
datos y lista

Palabras clave reservadas por el analizador léxico del lenguaje.

variable elementos = [1, 2, 3]
mostrar(elementos)

D. Palabras Clave de SQL Nativo en Español

base_datos

Abre o crea una base de datos SQL para las siguientes sentencias nativas.

base_datos "sistema.db"
crear_tabla

Crea una nueva tabla con la lista de columnas indicada.

base_datos "sistema.db"
crear_tabla clientes(id, nombre, ciudad)
insertar_en y valores

Inserta una fila en una tabla especificando columnas y sus valores correspondientes.

base_datos "sistema.db"
crear_tabla clientes(id, nombre, ciudad)
insertar_en clientes(id, nombre, ciudad) valores (1, "Lucía", "Monterrey")
seleccionar, de, donde, ordenar_por y limite

Consulta registros desde una tabla, filtra con donde, ordena con ordenar_por y acota con limite.

base_datos "sistema.db"
variable top = seleccionar nombre de clientes donde ciudad == "Monterrey" ordenar_por id desc limite 1
mostrar(top)
actualizar y poner

Modifica columnas de las filas que cumplan la condición indicada.

base_datos "sistema.db"
actualizar clientes poner ciudad = "Guadalajara" donde id == 1
eliminar_de

Elimina filas de una tabla (con filtro opcional donde).

base_datos "sistema.db"
eliminar_de clientes donde id == 1

E. Palabras Clave de Web Nativa en Español

pagina

Declara un documento web con su título y contenido hasta fin.

pagina "Portal ESP"
    encabezado "Bienvenido"
fin
estilo

Define reglas de estilo para un selector dentro de una página.

pagina "Estilos"
    estilo body
        fondo = "#080c17"
        color_texto = "#f1f5f9"
    fin
fin
script

Añade un bloque de lógica transpilada a JavaScript dentro de la página.

pagina "Con Script"
    script
        consola("Cargado desde ESP")
    fin
fin
encabezado, subtitulo y parrafo

Insertan títulos principales, subtítulos y párrafos de texto en la página.

pagina "Textos"
    encabezado "Título"
    subtitulo "Subtítulo"
    parrafo "Cuerpo del mensaje"
fin
entrada, enlace y imagen

Crean campos de entrada, hipervínculos e imágenes dentro de la página.

pagina "Elementos"
    entrada "tu_correo"
    enlace "Repositorio", "https://github.com/rafa247/web_esp"
    imagen "banner.png", "Banner"
fin
boton y al_clic

Agregan un botón interactivo y definen qué ocurre al pulsarlo con al_clic.

pagina "Interactiva"
    boton "Pulsar aquí" al_clic
        alerta("¡Botón pulsado!")
    fin
fin
contenedor

Agrupa elementos y sub bloques dentro de un contenedor.

pagina "Contenedor"
    contenedor "tarjeta"
        encabezado "Dentro de tarjeta"
        parrafo "Contenido agrupado"
    fin
fin
