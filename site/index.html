Usar módulos

Primero local. Luego tú decides.

ESP resuelve primero módulos estándar y locales; puede comprobar una versión exacta y cargar dependencias declaradas. Solo pide permiso antes de consultar el registro e instalar un módulo remoto.

01

Busca en local

conseguir nombre intenta resolver primero módulos estándar, del proyecto y ya instalados.

02

Solicita permiso

Si no lo encuentra, ESP pregunta si quieres buscar e instalar el módulo comunitario.

03

Instala si existe

Solo tras tu confirmación se consulta el registro; si el paquete existe, se descarga a tu carpeta de ESP.

Ecosistema abierto

Comparte lo que construyes.

Envía el módulo desde esta página: no necesitas instalar Git, usar una terminal ni tener una cuenta. Los envíos se publican automáticamente en el catálogo.

  1. Escribe el nombre, una descripción y el código ESP público del módulo.
  2. Completa la verificación antispam y pulsa Publicar módulo.
  3. Espera a que termine el despliegue del catálogo y ya podrás instalarlo.

Importante: la publicación es automática y no revisa la sintaxis. El código ESP es ejecutable: no incluyas contraseñas, tokens ni datos privados, y revisa el fuente antes de instalar módulos de otras personas.

Letras, números, guion y guion bajo. Máximo 1 MiB. El módulo quedará disponible para cualquier persona.
