1. Instalación y Registro Automático en el PATH

El binario esp.exe (v2.0.0) incluye intérprete interactivo (REPL), compilador nativo AOT y toda la librería estándar en un solo ejecutable:

  1. Descarga esp.exe desde el botón superior.
  2. Guárdalo en una carpeta permanente, por ejemplo C:\ESP\esp.exe.
  3. Al ejecutarlo por primera vez, verifica su ruta y se registra en el PATH de usuario para poder invocarse como esp desde cualquier directorio.
esp version
esp ruta
Get-FileHash "$HOME\Downloads\esp.exe" -Algorithm SHA256

🛡 ¿Qué hacer si Windows Defender o SmartScreen bloquea el ejecutable?

Como ESP 2.0.0 es un proyecto independiente sin certificado comercial de pago de Microsoft, SmartScreen o Windows Defender pueden mostrar una advertencia inicial.

Opción A: Permitir en Windows SmartScreen

  1. En la ventana "Windows protegió su PC", haz clic en Más información.
  2. Pulsa Ejecutar de todas formas para abrir esp.exe.

Opción B: Desbloquear desde PowerShell o Propiedades

Unblock-File -Path "$HOME\Downloads\esp.exe"

Opción C: Restaurar o excluir en Seguridad de Windows

  1. Abre Seguridad de Windows → Protección contra virus y amenazas → Historial de protección y restaura esp.exe si fue puesto en cuarentena.
  2. Agrega tu carpeta de trabajo o de compilación (por ejemplo C:\ESP) en Exclusiones para evitar avisos al generar tus propios .exe.

3. Fundamentos: Variables, Bucles y Funciones

Variables, Listas y Mapas

Las listas en ESP admiten indexación base 1 (y 0 para el primer elemento), y los mapas almacenan pares clave-valor.

variable nombre = "ESP 2.0.0"
constante MAX_REINTENTOS = 3

variable lenguajes = ["C++", "Rust", "ESP"]
agregar(lenguajes, "SQL")

variable ficha = {
    proyecto: nombre,
    version: 2,
    activo: verdadero
}

mostrar(lenguajes[3])
mostrar(ficha.proyecto)
mostrar("Total: " + texto(longitud(lenguajes)))

Condicionales, Bucles y Funciones

Usa si / si_no_si / sino, rangos con para i = 1 hasta 5 paso 1 o iteración con para x en lista.

funcion sumar(a, b = 10)
    devolver a + b
fin

para i = 1 hasta 5
    si i % 2 == 0 y i >= 2
        mostrar(texto(i) + " -> " + texto(sumar(i)))
    sino
        mostrar(texto(i) + " -> impar")
    fin
fin

4. Clases, Herencia y Manejo de Errores

Las clases soportan hereda, propiedades y métodos con visibilidad publico o privado, constructor iniciar y bloques intenta / si_no_puede.

clase Cuenta
    publico variable titular = ""
    privado variable saldo = 0

    publico funcion iniciar(titular, saldo_inicial)
        este.titular = titular
        este.saldo = saldo_inicial
    fin

    publico funcion depositar(monto)
        si monto <= 0
            afirmar(falso, "El monto debe ser positivo")
        fin
        este.saldo = este.saldo + monto
        devolver este.saldo
    fin
fin

clase CuentaVIP hereda Cuenta
    publico funcion bono()
        devolver este.depositar(50)
    fin
fin

intenta
    variable c = CuentaVIP("Rafa", 100)
    mostrar("Saldo final: " + texto(c.bono()))
si_no_puede err
    mostrar("Error controlado: " + err)
fin

5. Base de Datos SQL Nativa

ESP 2.0.0 incluye sentencias nativas de base de datos en español (base_datos, crear_tabla, insertar_en, seleccionar, actualizar, eliminar_de) y persistencia en disco.

base_datos "tienda.db"
crear_tabla productos(id, nombre, precio, stock)

insertar_en productos(id, nombre, precio, stock) valores (1, "Teclado", 45, 12)
insertar_en productos(id, nombre, precio, stock) valores (2, "Mouse", 25, 30)

actualizar productos poner precio = 29 donde id = 2

variable baratos = seleccionar nombre, precio de productos donde precio <= 50 ordenar_por precio asc limite 5

fin

6. Desarrollo Web Nativo (HTML5 + CSS3 + JS)

Declara páginas con pagina, estilos con estilo, elementos como encabezado, parrafo, entrada, enlace, imagen, contenedor y eventos al_clic, y expórtalos con guardar_web o html_web().

pagina "Panel ESP 2.0.0"
    estilo body
        fondo = "#0b1020"
        color_texto = "#edf2ff"
    fin

    contenedor "tarjeta"
        encabezado "Hola desde ESP Web"
        parrafo "Generado directamente en Español sin plantillas externas."
        entrada "correo"
        boton "Saludar" al_clic
            alerta("¡Botón ejecutado!")
        fin
    fin

    script
        consola("Página lista en el navegador")
    fin
fin

guardar_web("salida.html")
mostrar("HTML generado con éxito")
