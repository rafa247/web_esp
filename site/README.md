# ESP 2.0.0 — Lenguaje de Programación Nativo en Español

**ESP 2.0.0** es un lenguaje de programación compilado e interpretado escrito en C++17 con sintaxis 100% en español, motor SQL persistente integrado, generación nativa de aplicaciones Web (HTML5/CSS3/JS), compilación nativa a ejecutables `.exe` y librerías estándar de ciberseguridad, redes, WebSockets y desarrollo de sistemas operativos.

## Instalación en Windows

1. Descarga **`ESP-2.0.0-win64.exe`** desde el botón superior (o desde la carpeta `dist/`).
2. Ejecuta el asistente de instalación. El instalador **agrega automáticamente `esp.exe` al `PATH` del sistema** y asocia los archivos `.esp`.
3. Abre cualquier terminal (PowerShell o CMD) y ejecuta:
   ```powershell
   esp version
   esp mi_programa.esp
